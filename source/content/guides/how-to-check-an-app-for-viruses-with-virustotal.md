title: How to check an app for viruses with VirusTotal

VirusTotal is a free service that checks a file with many antivirus scanners at once. It is a good habit to check any app before you install it.

## Check a file

1. Open [www.virustotal.com](https://www.virustotal.com) in your browser.
2. Make sure the File tab is selected, then press Choose file.
3. Pick the APK or other file from your Downloads folder.
4. Wait while the file is uploaded and checked. This can take a minute.

## Read the result

- The result says how many security vendors flagged the file, for example "0 / 65". Zero means no scanner found a problem.
- If one or two less known scanners flag a file, it is often a false alarm, especially for apps that are new or rarely used. If many scanners flag it, do not install it.
- On Blind World Hub, an app page may also have a "Virus scan report" link that opens the VirusTotal report for that file directly.
