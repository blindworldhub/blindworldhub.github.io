title: How to install an APK file on Android
description: Step by step, with a screen reader: download an APK file from Blind World Hub and install it on your Android phone.
date: 2026-10-24
---
An APK file is an Android app that you install yourself, outside the Play Store. These steps work with TalkBack and Jieshuo. The names of some settings differ a little between phone makers.

## Download the file

1. Open the page of the app on Blind World Hub.
2. Under the heading "Download", press the download button. Its name tells you the app, the version and the size.
3. Your browser downloads the file. Chrome may ask whether to keep it; choose Download or Keep.

## Open the file

1. When the download has finished, open it from the notification, or open the Files app and go to Downloads.
2. Double tap the file to open it.

## Allow installing from this app (only the first time)

1. Android says that for your security, your phone is not allowed to install unknown apps from this source. Press Settings.
2. Turn on "Allow from this source" for Chrome or for your Files app.
3. Go back with the Back button or gesture. The installer opens again.

## Install

1. Press Install.
2. Google Play Protect may ask to scan the app, or say that it does not know it. Read the message: you can scan the app, or choose More details and then Install anyway if you trust the app.
3. When the installation has finished, press Open, or find the app in your list of apps.

## Updating an app

To update, download the new version from Blind World Hub and install it the same way. Your settings stay, as long as the new version comes from the same developer.
