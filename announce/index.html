Send a message to Smart TTS users

Your message pops up in Smart TTS when people open it, with an OK button. It is not shown on this website. This works from the next version of Smart TTS.

On the GitHub page

  1. Press "Create".
  2. About two minutes later the message is ready. Everyone who opens Smart TTS sees it once.
  3. To stop showing the message, close that issue on GitHub. To change it, edit the issue.
